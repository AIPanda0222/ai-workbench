# 通用启动指令

在**已经打开你的工作台目录**且已按需要授权后，把下面文字发给智能体。路径均以该工作台根目录为准。

```text
请先确认你是否能访问当前工作台目录。能访问时，读取根目录 AGENTS.md 和 README.md，遵循其中规则协助我完成任务；按 knowledge/experience-index.md 的路由，只阅读本任务命中的经验。先检查现有项目，判断继续原工作线还是新建；不要因为新对话或新版本自动新建项目。

如果无法读取或写入，请明确指出，并告诉我需要粘贴哪些文件或手动执行哪些步骤。区分你已经实际完成的操作、建议和尚未验证的内容。敏感数据、外部发布、费用和权限按我的明确授权处理。

我的任务是：[在此填写目标、材料与预期交付]
```

如果智能体会自动加载项目规则，此指令仍可用于确认工作目录和任务；不同产品的规则发现机制不完全相同，以产品当前文档和实际测试为准。
