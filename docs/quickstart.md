# 快速开始

## 第一次建立

1. 下载并解压本仓库；自行选择本地保存位置，不需要上传个人资料。
2. 新建空目录，将 `starter/` **内容**复制进去，含隐藏的 `.gitignore` 和 `.github/`。复制完成后确认根目录存在 `AGENTS.md`、`README.md`、`knowledge/`、`projects/`、`templates/`。
3. 在可访问本地目录的智能体里打开该目录。如果它没有自动读 `AGENTS.md`，发送 [启动指令](agent-prompt.md) 并确认它实际读到文件。
4. 说出一个实际目标，例如“整理一份学习计划”，让智能体先判断工作线与资料边界，再在 `projects/` 下按模板建项目。完成后查看项目 README、交付物与验证记录。

默认模板没有联网、自动执行命令、安装插件或上传资料。不同产品的访问权限和云端处理方式由该产品及你的设置决定；敏感资料加入之前，先了解其数据处理政策。

私人工作台默认不要整体推送到公开仓库。若要分享方法，请在独立目录准备公开副本并逐项审核；`.gitignore` 不能保证隐私。

## 我已有工作台

请按 [已有框架优化指南](upgrade.md) 操作，直接复制 [改造提示词](upgrade-prompt.md) 给智能体，先备份并只读检查，再按授权在独立副本试用。保留原件、规则、链接与历史，不将模板覆盖到已有目录。

## 只有聊天，不能访问文件

让智能体先阅读你手动粘贴的启动指令和规则，输出目录及文件草稿；由你手动创建、保存并回传需要它继续处理的片段。它不能仅凭回答声称已经读取或写入本地文件。

## 后续日常

同一工作线直接告诉智能体项目和本轮目标；它应回查当前 README，并按工作类型索引选读。纯问答不强制建项目；同一阶段连续工作不反复执行完整启动流程。
