# 隐私与公开检查

模板仅提供空结构。个人工作台、项目原件、聊天记录、偏好、身份信息、客户或研究资料，以及密钥和令牌，应由使用者自行保管。

## 准备公开自己的版本

1. 在独立目录从空白开始准备公开副本；只添加明确允许公开的文件。不要把个人工作台整个复制进公开仓库后再尝试删减。
2. 检查正文、文件名、目录、链接、截图、图片元数据、文档批注、隐藏文件、配置、日志和 Git 历史。特别检查账号邮箱、机器用户名、绝对路径、真实项目或客户名称、敏感数据及凭据。
3. 检查第三方材料的许可、署名和引用范围。对不能确认可再分发的内容，用自己的话概括方法并链接原文。
4. 让另一轮独立检查逐文件审核，并使用合适的秘密扫描工具；自动扫描不能证明不存在所有隐私。确认公开文件清单、仓库可见性和提交身份后再发布。
5. 如果公开了秘密，及时撤销或轮换该凭据，并处理发布平台上的历史记录；仅从最新文件中删除不能撤回已传播的数据。

`.gitignore` 只是辅助：它不清除已跟踪文件或历史，也不能替代发布前审查。使用任何云端智能体时，资料可能按服务条款送到服务端处理；请先确认数据处理方式。
