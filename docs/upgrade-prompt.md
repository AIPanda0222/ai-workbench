# 已有框架改造提示词

把下方文字复制给你使用的智能体。填写现有框架位置、授权范围和当前痛点；若无法让它访问文件，可先提供非敏感的目录清单和相关规则片段。默认诊断只读，后续由使用者自行决定是否授权改动。

```text
我已有一套知识库或 AI 工作台，目标是在保留现有资料、链接、规则、知识和历史的基础上，选择性吸收以下做法：项目接续、原件/过程/交付区分、按任务类型选读经验、交付证据分层、可复用知识与索引日志维护。

现有位置：[填写位置，或说明只能提供哪些片段]
目前痛点：[填写，例如每次都读全部历史、跨会话找不到项目状态]
本轮授权：[只读诊断 / 已准备独立备份副本并授权修改该副本；写明具体范围]

请先确认你能否访问上述材料和实际可用工具；不能访问时，明确需要我提供什么，不要假装已读取。先检查现有目录、已有规则与项目入口，按任务定向阅读；识别个人信息与不可公开内容。不要安装 Obsidian、启用同步、上传资料、付费或访问外部系统，除非我另有明确授权。

请列出：现有能力与目录映射、值得保留的部分、实际缺口、最小改进方案、规则或文件同名冲突、拟修改的具体路径和可验证的回退方法。优先沿用已有结构和权威规则，不复制整个模板、不删除或覆盖原件、不静默替换冲突规则。对仅聊天的情况，给我可以手动执行的步骤及文件草稿。

若我只授权诊断，到此停止。若我已明确授权修改独立副本：先确认备份可用，再逐项修改副本，保留变更前版本；完成后检查原有链接、选读路由、项目接续和回退能力，列出真实执行的操作、证据及未测试范围。不要把建议写成已完成，也不要未经授权修改正式工作区。
```
