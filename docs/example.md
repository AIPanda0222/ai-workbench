# 从一个虚构任务开始

本例是演示流程，不代表任何产品的真实运行测试。

1. 目标：“用提供的公开资料，制作一页学习计划。”智能体确认资料可用和交付格式，先查 `projects/README.md`；没有相同工作线时，复制 `templates/project/` 到新的项目目录。
2. 它根据经验索引选择资料整理和文档交付相关内容，读取证据方法；不读取无关的媒体方法卡。
3. 将用户提供、允许使用的确定版本放在项目 `inputs/`；草稿放 `work/`；完成品放 `outputs/`，项目 README 记录当前阶段。
4. 它打开本轮成品并检查内容和格式，将检查对象、方法、结果及未检查项记录在项目中。如果无法真实打开，就明确说明。
5. 下次用户要求修改同一计划时，回到原项目；仅对修改及受影响处重新核验。若总结出跨项目可复用的方法，先查知识索引，再更新卡片与日志。

整个过程中不需要自动把项目资料公开或上传到 GitHub。
