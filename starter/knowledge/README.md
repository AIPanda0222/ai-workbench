# 知识维护

本区保存跨项目可复用的综合，不替代原始资料。先看 [知识索引](index.md)，具体工作经验从 [经验索引](experience-index.md) 进入。

- **摄入**：确认来源及版本 → 判断复用价值 → 查已有卡片 → 更新或创建 → 链接相关主题 → 更新索引和日志。
- **查询**：按索引定向读取，必要时回溯原件；区分事实、推断、缺口和证据范围。有复用价值的分析才写回，不把模型自己的回答当成新的独立证据。
- **检查**：按需检查链接、来源、重复、过期和矛盾；结构通过不代表事实正确。保留冲突与版本，重要判断交由用户确认。

卡片使用 `templates/knowledge-card.md`，重要内容说明来源、日期、状态、适用范围及尚未核实的部分。追加 `log.md` 时记录实质变化；一次性问答无需留痕。
