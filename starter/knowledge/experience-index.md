# 工作类型经验索引

只读本轮交付命中的类型；混合任务读相关类型。出现具体问题，再查相关卡片和原始证据，不需要全文阅读所有历史项目。

| 任务 | 按需阅读与关注 |
|---|---|
| 持续项目或修改旧版本 | [项目连续性与变更范围](methods/project-continuity.md) |
| 资料整理与研究 | 来源、时效、事实与推断、引用范围；[证据与验收](methods/evidence-and-quality.md) |
| 文档、表格与演示 | 最终文件可打开性、内容和格式、公式或编辑能力；[证据与验收](methods/evidence-and-quality.md) |
| 图像、音视频 | 尺寸、时长和用户体验；[媒体按需阅读](methods/media-reading.md)、[证据与验收](methods/evidence-and-quality.md) |
| 软件与交互 | 实际功能、典型及边界场景、依赖、运行环境；[证据与验收](methods/evidence-and-quality.md) |
| 工具安装与环境 | 来源、许可、权限与可用性；安装成功不等于功能已验证 |
| 其他 | 按交付和风险选读现有卡片；确有价值时再补充 |

这些是可调整的通用方法，并不代表任何具体项目已验证。实践后可链接自己的方法卡，并记录来源与适用范围。
