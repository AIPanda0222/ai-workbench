# 启动智能体

在能访问本工作台目录的智能体中打开此目录，将下面指令和你的目标发给它：

```text
请确认你能否访问当前工作台目录。能访问时，先读取根目录 AGENTS.md 和 README.md，并按其中规则完成我的任务；只选读 knowledge/experience-index.md 中本任务需要的类别。先判断接续现有项目还是建立新项目；区分已经实际完成的操作和未验证的内容。敏感资料、外部发布、费用和权限遵循我的明确授权。无法访问时，说明需要我手动提供或执行什么。

我的目标：[填写任务、材料和期望交付]
```

工具自动加载规则的能力和具体授权因产品而异；要求它说明实际读取了什么。只有聊天能力时，可手动粘贴规则并手动保存文件。
