# 我的 AI 工作台

本目录是项目、知识和规则的入口。先读 [AGENTS.md](AGENTS.md)，按 [项目索引](projects/README.md) 接续工作；按 [经验索引](knowledge/experience-index.md) 选择本次任务需要的经验。

- `projects/`：各项目的输入、过程、交付、文档和验证记录。
- `knowledge/`：经过整理、可跨项目复用的知识。
- `templates/`：新项目及知识卡的空白模板。

不知道如何开始时，复制 [启动指令](START-HERE.md) 给智能体。使用前先查看下载包中的快速开始和隐私说明。根据自身需要更改目录和规则时，保持入口与实际位置一致。
